## 2. 😐FaceRecognition

> 얼굴인식 성능 향상을 위한 방식 제안(개인 프로젝트)
>
> - 개발기간 : 2023-2024
> - 핵심 역할 : CNN모델을 이용하여 2가지 방식의 얼굴 인식 방식 제안
>
>> Back-end
>> - Language : python3  
>> - Skill : openCV, numpy, dlib, matplotlib, pytorch
> 
>> 프로젝트 상세 설명(Back-end)
>> 1. 각 인물로 되어있는 5개의 클래스의 얼굴 이미지를 원본 이미지, 원본 이미지를 원근변환한 이미지, 랜드마크만 표시한 이미지로 각각 학습하여 성능을 비교하였습니다.
>> 1. BalancedCNN 기반 얼굴인식 분류 파이프라인을 PyTorch로 구현하고, 동일 모델에 **세개의 데이터셋(원본 / 원근변환 / 랜드마크)**만 교체해 공정한 성능 비교가 가능하도록 구성했습니다.
>> 2. 전처리 단계에서 얼굴 정렬 → 원근변환(OpenCV warpPerspective) → 랜드마크 추출 후 스케치/마스크화로 세 가지 입력을 생성하여 각각의 폴더에 저장하고, 모두 128×128 정규화·증강 및 흑백처리를 동일하게 적용했습니다.
>> 3. 학습/평가 루프는 동일 하이퍼파라미터(배치, 에폭, 옵티마이저 등)로 세 모드를 각각 실행하도록 만들었습니다.
>> 4. 결과 ppt는 모드별 **정확도(Accuracy), 손실(Loss), 시간(Time: 학습/추론 측정), 정밀도(Precision)**를 자동 수집·저장하고, 비교 표/곡선으로 시각화해 차이를 한눈에 파악할 수 있게 했습니다.
>
