## 2. 😐FaceRecognition

> 얼굴인식 성능 향상을 위한 방식 제안(개인 프로젝트)
>
> - 개발기간 : 2024.02 - 2024.08
> - 핵심 역할 : CNN모델을 이용하여 2가지 방식의 얼굴 인식 방식 제안
>
>> Back-end
>> - Language : python3  
>> - Skill : openCV, numpy, dlib, matplotlib, pytorch
> 
>> 프로젝트 상세 설명(Back-end)
>> 1. 얼굴 인식의 정면성을 해결하고 사용자가 측면이나 다양한 각도에서 얼굴을 제시하더라도 정확하게 인식할 수 있는 얼굴 인식 시스템을 제안하기 위해 시작하였습니다.
>> 2. 각 인물로 되어있는 5개의 클래스의 얼굴 이미지를 원본 이미지, 원본 이미지를 원근변환한 이미지, 랜드마크만 표시한 이미지로 각각 학습하여 성능을 비교하였습니다.
>> 3. CNN 기반 얼굴인식 분류 파이프라인을 PyTorch로 구현하고, 동일 모델에 ***세개의 데이터셋(원본 / 원근변환 / 랜드마크)*** 만 교체해 공정한 성능 비교가 가능하도록 구성했습니다.
>> 4. 학습/평가 루프는 동일 하이퍼파라미터(배치, 에폭, 옵티마이저 등)로 세 모드를 각각 실행하도록 만들었습니다.
>> 5. 성능비교는 모드별 ***정확도(Accuracy), 손실(Loss), 시간(Time: 학습/추론 측정), 정밀도(Precision)*** 를 기준으로 비교하고, 비교 표/곡선으로 시각화해 차이를 한눈에 파악할 수 있게 했습니다.
>> 6. 결과적으로 원본이미지는 97.8%, 원근 변환 이미지는 99%, 랜드마크 이미지는 91.2%의 정확도가 나왔습니다. 
>

>> - Skill : flask, tensorflow, pandas, matplotlib, html, css
